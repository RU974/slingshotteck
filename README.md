# Slingshot

Slingshot is a growth-focused marketing site for a service-business brand that wants to capture more leads, automate follow-up, and convert enquiries into booked jobs.

## Getting Started

1. Install dependencies
```bash
npm install
```

2. Run the development server
```bash
npm run dev
```

3. Build for production
```bash
npm run build
```

## Project Notes

This site is configured for the Slingshot brand and can be customized further for your specific offers, pricing, services, and lead capture workflow.
